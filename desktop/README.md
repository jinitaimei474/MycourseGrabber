# 交大助手 · Windows 桌面版 1.3

**1.3 新增实时空闲场次与误提示处理**：新版位于 `release/1.3.0/SJTU-Assistant-win32-x64/SJTU-Assistant.exe`。退出旧版后打开新版，保留整个发布文件夹。课程、水源功能及专用 Edge 登录配置继续使用原数据目录。

## 实时空闲场次

连接场馆后，在“空闲场次”中选择日期、东区/胡晓明或两个场馆，设置开始不早于和结束不晚于。例如 18:00–22:00 会列出 18:00–19:00 至 21:00–22:00 的可用场地及价格。点击“查询并持续监测”，默认每轮完成后 5 秒再次读取，可设为 3–60 秒。具体可预约日期按网站返回，不用截图日期猜测；尚未开放的场馆会显示提示。

每个空闲场次可点“预约此场”；也可勾选 1–30 个，再点“预约所选候选”。多个场次按照勾选顺序作为备选，成功生成一个订单即停止，遵守同账号同预约日仅一场的限制。点击后先停止监测，再由原预约流程重新检查余量与已有订单，最长尝试 5 分钟，之后生成微信二维码并提醒扫码。监测本身不会下单。

列表显示更新时间；刷新失败、登录变化会停止监测并清除旧余量，过期结果不能点击预约。新一轮发现场地已无余量，会自动移除相应勾选。停止监测后才能修改筛选条件；恢复监测需重新点击。监测期间课程、水源及其他网球任务互斥。重启不自动监测。

学校首页存在正常账号也显示“账号禁用提示”的前端分支。软件读取网站账号状态，确认正常时点击该弹窗的关闭按钮；真实禁用或无法核实状态时停止并显示原因，不更改网站限制。此修复也应用于预约和进入支付详情时。

## 网球预约

1. 左侧选择“网球预约”。添加首选与备选，每项分别填写东区/胡晓明网球场、日期、单个一小时时段，以及可选的场地编号；编号留空代表任意可用小场地。用上下箭头调整优先级。
2. “按首选日期计算放号时间”默认设为预约日期前七天北京时间 12:00，结束时间为五分钟后。网站是否包含当天等具体日期范围以实际返回为准；可以修改开始与结束时间，也可点击“现在开始”检查已开放时段。每轮间隔为 1–60 秒，默认三秒；请求串行执行。
3. 填入备用 jAccount 用户名/密码并“连接场馆预约”。优先使用专用 Edge 已有场馆会话，否则打开交我办，搜索“场馆预约”，进入学校平台。网页已有字段不覆盖；密码只保留本次进程内存。未完成登录时在 Edge 操作后重新连接。
4. “启动预约”会按顺序选择场馆、日期、场地和时段，点击立即下单，勾选接受预订规定，提交订单，再走立即支付、规定提示确认、微信支付下一步及确认步骤。第一次生成订单后，本次预约任务停止继续尝试其他候选。
5. 微信缴费二维码生成后自动保存到本机数据目录 `tennis-qr/`，软件展示二维码及网站提供的付款期限，同时提示音、窗口提醒和 Windows 通知提醒你扫码付款。可点击“保存二维码”另存 PNG；只有你扫码才会实际付款。系统通知设置可能影响通知显示，软件内的二维码和状态始终可见。
6. 扫码后点“核对订单状态”，网站确认后才显示“预约成功”。“继续获取二维码”针对已有待付款订单恢复支付流程，不会重新下单。失效二维码只标为到期，不视为预约成功。
7. 滑块或其他未知验证在 Edge 手动完成，再核对订单。提交结果不明、网络中断或软件退出后，会保留该账号与日期的保护记录。网站有有效订单时禁止重复预约；已在网站核实没有订单后才使用“解除保护”。

预约配置和提交记录保存于 `%APPDATA%/SJTU Assistant/tennis.json`，不保存密码；二维码保存于相邻的 `tennis-qr`。重启不自动运行预约。三个模块共用专用 Edge，运行操作互斥。运行期间软件请求系统保持唤醒；仍需保持软件、Edge、网络和电脑可用。二维码生成表示待付款，预约是否最终成功由学校确认。

网球实现位于 `src/modules/tennis/`，使用已核实的学校公开页面结构及原页面提交功能。支付操作限定学校 `cwc2.jdcw.sjtu.edu.cn`；网站结构或支付方式无法辨认时停下并提示人工检查。未替用户提交任何真实预约；模拟网站与真实 Electron 界面验证不代替真实账户线上验收。

开发验证：`npm test`、`npm run test:tennis`。所有网球浏览器/UI 测试拦截学校和缴费网址，不发送真实订单或支付请求。

独立桌面窗口管理账号连接、课程查询、多课程任务和定时刷新。运行时打开专用 Edge，通过 jAccount 登录后悬浮“选课”并进入“自主选课”。无须安装扩展或粘贴控制台代码。

**1.1 新增内置水源模块**：左侧“水源帖子”中按标题、编号/网址或帖主检索，选择类别和标签筛选，勾选帖子后按发言用户采集，导出带发帖时间的 TXT / JSON。新版程序位于 `release/1.1.0/SJTU-Assistant-win32-x64/SJTU-Assistant.exe`，需保留旁边的依赖文件。请退出旧版后启动新版，原课程任务和专用 Edge 配置仍使用同一用户数据目录。

## 水源帖子

1. 进入“水源帖子”，点击“连接水源”。首次使用会打开专用 Edge；若跳转登录页，在该窗口完成登录，再点击连接。与课程助手共用专用 Edge 的登录会话，但水源使用独立标签页；不要求先连接教务系统，也不读取课程账号密码。日常 Edge 的登录不会自动继承。
2. 选择查找方式。默认接受帖子标题关键词、编号和网址；按帖主时填 `@` 后的账号用户名，例如 `alice` 或 `@alice`，不是昵称。帖主查询只查其发起的主题，不包含仅回复过的主题。
3. 类别和标签从当前水源账号可访问的接口读取。类别包含子类别；标签可输入或从建议中选择一个，精确筛选。允许不填关键词，仅按类别或标签查找。主题本身可以没有标签。
4. 点击“查找帖子”，结果显示标题、编号、帖主、类别、标签和楼层数量。勾选需要的主题，或选择已加载结果（每次最多 50 个）。点击“加载更多帖子”继续检索；搜索受论坛索引和权限限制，页面候选并不保证包含全站所有主题。
5. “爬取用户”填 `全部`（默认），或填多个发言者用户名，用逗号分隔。这个条件与帖主筛选独立：可以检索 Alice 发起的主题，只导出 Bob 的回复。需要时展开时间范围，按北京时间输入日期或完整时间；结束日期包含当天全天，留空不限。
6. 点击“采集所选帖子”。软件依次读取主题完整楼层索引，分批补齐正文，再按用户和发帖时间筛选，显示实时进度。可以停止，已取得的结果保留并标为不完整。
7. 导出 TXT / JSON 时选择本地保存位置。每条发言都附作者、楼层、发帖时间和原帖链接；JSON 同时保留 UTC 与北京时间、Markdown 原文、HTML、主题类别/标签和完整性信息。预览最多 30 条，每条截取 3000 字，**导出不做此截断**。

采集结果仅在本次进程内存中；开始新采集会替换旧结果，退出前请导出。仅抓当前账号可见的内容，不恢复已删除或无权访问的楼层，不下载图片/附件文件。每批最多 20 楼，请求至少间隔 1 秒，登录失效、访问被拒绝或长时间限流时停止并报告。切换水源账号后清空旧账号结果。水源操作和课程操作互斥，运行课程任务时先停止，再进行水源采集。

## 运行

支持 Windows 10/11 x64，需已安装 Microsoft Edge。解压发布包后双击 `SJTU-Assistant.exe`；必须保留整个文件夹，不能只复制 EXE。最终用户不需要 Node.js 或 Python。

1. 在软件填写 jAccount 用户名、密码。已有网页自动填充时不覆盖；只补全空字段。密码只保留在本次进程内存中，不写入任务配置或日志。
2. 点击“打开 Edge 并连接”。软件使用独立浏览器配置，日常 Edge 的登录状态不会自动继承。验证码使用 Windows 本地 OCR，识别/验证失败最多尝试三次；遇到错误密码、额外验证或 OCR 不可用，保留浏览器窗口并提示手动处理。在 Edge 完成登录后，回软件再次点击连接。
3. 选择课程类别，输入课程名称、课号或教师姓名；多个关键词用逗号或换行分隔。只填教师也能查询；同时填课程和教师时按教师筛选结果。
4. 点击教学班的“加入”。最多十门不同课程，同课可选多个备选教学班，任一班成功即完成该门。
5. 设置北京时间开始/结束时间、5–60 秒轮询间隔、0–120 分钟整页刷新（默认 60，0 关闭）。点击“启动全部任务”后将真实执行选课。到期或全部成功停止。
6. 每次检查先填课号并重新查询；软件保存进度，整页刷新后继续。刷新是否能延长学校凭证期限未被确认；必要时会重新走登录流程，需要人工处理时暂停并提示。
7. 学校确认弹窗需要本人处理。提交结果不明时整门课冻结；先停止任务、核对网站已选列表，再点“已核对未选上，允许重试”，然后重新启动。

重启软件只恢复课程/配置/进度，不自动开始抢课。运行期间保持电脑、软件、Edge 和网络可用；无需窗口置顶。软件运行任务时请求系统保持唤醒，但不能保证断电、系统更新或人为休眠期间继续运行。

本机数据默认位于 Electron 用户数据目录 `%APPDATA%/SJTU Assistant`（任务文件 `tasks.json`、专用 Edge 配置 `edge-profile`）；可通过开发环境变量 `SJTU_ASSISTANT_DATA_DIR` 指定测试目录。浏览器自身可能保存登录 Cookie，这是独立配置维持会话所需；应用不会导出这些 Cookie。发布包不包含任何测试账户、验证码或本机浏览器配置。

## 开发与打包

安装 Node.js 22.12 或更新版本，在本目录运行：

```powershell
npm ci
npx install-electron
npm start
```

Electron 44 的运行时需要显式安装；启动前自动同步根目录 `course-timer.user.js` 到 `vendor/`。此副本仅复用页面适配器，桌面宿主持有调度，网页内不会生成旧版扩展面板。

```powershell
npm test
npm run test:browser
npm run test:ui
npm run test:shuiyuan
npm run build
npm run test:package
```

浏览器测试拦截所有学校网址并返回本地模拟页面，不发送登录/选课请求。UI 测试使用隔离数据目录，并在测试中替换外部浏览器服务。构建产物位于 `release/<版本号>/SJTU-Assistant-win32-x64/`。构建脚本优先使用 `../artifacts/electron-download/` 中对应版本的官方 Electron ZIP；没有本地 ZIP 时使用官方自动下载。同步脚本同时复制原水源爬虫核心到 `vendor/shuiyuan-core.js`，两个功能均随软件打包。

## 模块边界

| 文件/目录 | 职责 |
| --- | --- |
| `src/main.cjs` | 应用生命周期、受限 IPC、操作互斥 |
| `src/preload.cjs` | 向本地界面暴露有限命令 |
| `src/ui/` | 暖白浅青绿界面，不加载学校网页 |
| `src/services/browser.cjs` | Edge 登录、验证码、选课页导航与原适配器桥接 |
| `src/services/ocr.cjs`、`scripts/ocr.ps1` | 本地 Windows OCR，图像用后删除 |
| `src/services/store.cjs` | 任务持久化及账户隔离，不保存密码 |
| `src/services/scheduler.cjs` | 宿主轮询、停止、截止时间、结果不明保护 |
| `src/modules/index.cjs` | 课程与水源模块目录 |
| `src/modules/shuiyuan/` | 水源会话、类别/标签、检索、批量采集及导出 |
| `src/ui/shuiyuan.js` | 水源筛选表单、多选结果、进度及安全文本预览 |

水源模块通过专属受限 IPC 调用，只允许预先定义的水源 GET 接口；渲染器不能提交任意网址、文件路径或命令。已有 `../shuiyuan-crawler` 扩展可独立使用，桌面版复用其核心而不注入旧扩展面板。
