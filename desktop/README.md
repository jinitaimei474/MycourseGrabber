# 交大助手 · Windows 桌面版 1.0

独立桌面窗口管理账号连接、课程查询、多课程任务和定时刷新。运行时打开专用 Edge，通过 jAccount 登录后悬浮“选课”并进入“自主选课”。无须安装扩展或粘贴控制台代码。

## 运行

支持 Windows 10/11 x64，需已安装 Microsoft Edge。解压发布包后双击 `SJTU-Assistant.exe`；必须保留整个文件夹，不能只复制 EXE。最终用户不需要 Node.js 或 Python。

1. 在软件填写 jAccount 用户名、密码。已有网页自动填充时不覆盖；只补全空字段。密码只保留在本次进程内存中，不写入任务配置或日志。
2. 点击“打开 Edge 并连接”。软件使用独立浏览器配置，日常 Edge 的登录状态不会自动继承。验证码使用 Windows 本地 OCR，识别/验证失败最多尝试三次；遇到错误密码、额外验证或 OCR 不可用，保留浏览器窗口并提示手动处理。在 Edge 完成登录后，回软件再次点击连接。
3. 选择课程类别，输入课程名称、课号或教师姓名；多个关键词用逗号或换行分隔。只填教师也能查询；同时填课程和教师时按教师筛选结果。
4. 点击教学班的“加入”。最多十门不同课程，同课可选多个备选教学班，任一班成功即完成该门。
5. 设置北京时间开始/结束时间、5–60 秒轮询间隔、0–120 分钟整页刷新（默认 60，0 关闭）。点击“启动全部任务”后将真实执行选课。到期或全部成功停止。
6. 每次检查先填课号并重新查询；软件保存进度，整页刷新后继续。刷新是否能延长学校凭证期限未被确认；必要时会重新走登录流程，需要人工处理时暂停并提示。
7. 学校确认弹窗需要本人处理。提交结果不明时整门课冻结；先停止任务、核对网站已选列表，再点“已核对未选上，允许重试”，然后重新启动。

重启软件只恢复课程/配置/进度，不自动开始抢课。运行期间保持电脑、软件、Edge 和网络可用；无需窗口置顶。软件运行任务时请求系统保持唤醒，但不能保证断电、系统更新或人为休眠期间继续运行。

本机数据默认位于 Electron 用户数据目录 `%APPDATA%/SJTU Assistant`（任务文件 `tasks.json`、专用 Edge 配置 `edge-profile`）；可通过开发环境变量 `SJTU_ASSISTANT_DATA_DIR` 指定测试目录。浏览器自身可能保存登录 Cookie，这是独立配置维持会话所需；应用不会导出这些 Cookie。发布包不包含任何测试账户、验证码或本机浏览器配置。

## 开发与打包

安装 Node.js 22.12 或更新版本，在本目录运行：

```powershell
npm ci
npx install-electron
npm start
```

Electron 44 的运行时需要显式安装；启动前自动同步根目录 `course-timer.user.js` 到 `vendor/`。此副本仅复用页面适配器，桌面宿主持有调度，网页内不会生成旧版扩展面板。

```powershell
npm test
npm run test:browser
npm run test:ui
npm run build
npm run test:package
```

浏览器测试拦截所有学校网址并返回本地模拟页面，不发送登录/选课请求。UI 测试使用隔离数据目录，并在测试中替换外部浏览器服务。构建默认产物位于 `release/SJTU-Assistant-win32-x64/`。构建脚本优先使用 `../artifacts/electron-download/` 中对应版本的官方 Electron ZIP；没有本地 ZIP 时使用官方自动下载。

## 模块边界

| 文件/目录 | 职责 |
| --- | --- |
| `src/main.cjs` | 应用生命周期、受限 IPC、操作互斥 |
| `src/preload.cjs` | 向本地界面暴露有限命令 |
| `src/ui/` | 暖白浅青绿界面，不加载学校网页 |
| `src/services/browser.cjs` | Edge 登录、验证码、选课页导航与原适配器桥接 |
| `src/services/ocr.cjs`、`scripts/ocr.ps1` | 本地 Windows OCR，图像用后删除 |
| `src/services/store.cjs` | 任务持久化及账户隔离，不保存密码 |
| `src/services/scheduler.cjs` | 宿主轮询、停止、截止时间、结果不明保护 |
| `src/modules/index.cjs` | 模块目录，已有课程模块和水源预留入口 |

后续水源功能可新增 `src/modules/shuiyuan/` 服务与界面，向主进程注册专属受限命令。现有 `../shuiyuan-crawler` 保持独立，本版尚未接入爬帖，界面明确标为待接入。不要让新增模块依赖选课账号密码或任意文件/命令执行接口。

## 验证边界

模拟测试验证多课调度、防重复提交、停止、截止时间、账户变化、字段补全、有限 OCR 重试、菜单点击展开、类别切换后的延迟查询及真实 Electron 界面。2026-09-20 已在真实账户验证本地 OCR 登录、进入自主选课、查询 EE2905 并读取 10 个教学班；测试没有提交选课。学校类别切换后有延迟自动查询，桌面版会等待这次查询再开始用户查询，避免课程列表被覆盖。

验证码自动识别可能失败，仍需保留手动登录方式。没有实测连续两小时运行，也未确认学校登录凭证的固定期限或刷新续期效果；不保证一定获得名额。未签名的本地构建可能显示 Windows 来源提示，本版本未提交应用商店。
