# 交大定时选课助手 · 初版

在已经登录的上海交通大学自主选课页面中运行，读取指定教学班，按北京时间定时检查余量。有名额时点击网站原有的“选课”按钮。无需提供密码、Cookie，也不需要安装 Python 或启动后端。

**当前进度：已导出真实源码；已在真实页面识别 66 个教学班；只读检查与余量刷新通过验证。尚未进行真实选课提交，也未设置自动选课任务。**

## 现在怎样使用

本次会话已在当前 Edge 选课标签页注入面板。它位于页面右下角，默认勾选“仅检查”。如果页面已刷新或关闭，需要重新加载。

1. 在原网站选好课程类别，输入课程号查询，并展开目标课程的教学班列表。
2. 点击面板中的“读取当前教学班”，从下拉框选择具体教学班，核对课程、教师、时间、人数。
3. 保持“仅检查”勾选，点击“执行检查”。这一步立即读取当前页面，不等定时、不刷新余量、不提交。
4. 准备正式执行时，填写**未来的北京时间**，设置检查间隔和次数，取消勾选“仅检查”，再点“启动定时选课”。这一步才会启动真实任务。
5. 保持此标签页在前台、电脑联网且不睡眠。成功、次数耗尽或出现需要处理的情况时自动停止，也可随时点“停止”。

初版一次只处理一个教学班；不会自动退课或替换已选教学班。刷新网页会取消任务，重新打开后不会自动恢复。

## 下次使用：安装本地 Edge 扩展

无需扩展商店账户。

1. 解压 `dist/sjtu-course-timer.zip` 到一个固定位置。
2. 在 Edge 地址栏打开 `edge://extensions`，打开“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择解压后**包含 manifest.json 的文件夹**。
4. 刷新自主选课页面，右下角会出现面板。扩展只匹配交大自主选课页面。

扩展安装入口已提供，尚未替你安装到 Edge；本次使用的是控制台临时加载方式。

若已有用户脚本管理器，也可安装 `course-timer.user.js`。脚本要求在网页主环境中运行（`@grant none`），以复用学校页面的函数。

临时加载：复制 `course-timer.user.js` 的**全部内容**，在选课页按 F12，切换“控制台”，粘贴执行。如浏览器阻止粘贴，改用上面的本地扩展方式。`copy-script.ps1` 可将整个脚本复制到剪贴板。

## 范围和停止条件

- 检查间隔为 5–60 秒，最多检查 100 次，一次运行最长 30 分钟。默认每 5 秒检查，最多 60 次。
- 满员时重新查询余量；有空位时只提交一次。竞争导致提交时又满员，也停止本次任务，请处理原页面提示再决定是否重启。
- 前置校验、先修课、学分限制、冲突提示仍由原网站处理。弹窗需要人工处理，不会自动点击确认。
- 响应超时、登录失效、教学班信息变化、切换选课类别或页面不在前台时停止。未确认的提交结果不会自动重试。
- “停止”无法撤销已发出的服务器请求；如果已经点击过选课，需要自行核对右侧已选列表。
- 当前只支持已加载的单个教学班，不自动处理父子教学班组合、权重选择、购物车或验证码。
- 时间以本机时钟换算的北京时间为准。浏览器调度、系统休眠、网络延迟均会影响触发时间，不能保证抢到名额或毫秒级准点。若开始时已迟到超过 5 秒，任务拒绝启动。
- 初版需要提前进入可查询的选课页面并加载目标教学班；不自动从“尚未开放”页面刷新跨入新一轮选课。

## 技术栈

| 部分 | 使用技术 | 原因 |
| --- | --- | --- |
| 运行脚本 | 原生 JavaScript | 直接复用当前登录页面 |
| 网站适配 | DOM + 网站已有 jQuery 事件 | 读取真实教学班、观察响应、使用原有选课校验 |
| 面板 | Shadow DOM + HTML/CSS | 面板样式与学校样式分离 |
| 安装 | Edge / Chromium Manifest V3 本地扩展 | 重新进入选课页时自动显示面板 |
| 开发验证 | Node.js 内置 node:test | 零第三方依赖，测试不连接学校网站 |

Playwright 适合后续增加多课程、外部任务调度和日志，但当前 Edge 未开启调试端口，不能直接通过 CDP 接管原实例。相关能力见 [Playwright 官方说明](https://playwright.dev/docs/api/class-browsertype#browser-type-connect-over-cdp)。扩展使用 `world: MAIN` 与原页面共享 JavaScript 环境，见 [Chromium 官方说明](https://developer.chrome.com/docs/extensions/reference/manifest/content-scripts)。

## 文件与验证

- `course-timer.user.js`：完整脚本，浏览器运行不依赖 Node。
- `manifest.json`：本地扩展入口。
- `docs/source-analysis.md`：基于实际源码的接口和参数分析。
- `artifacts/`：原始 HTML、动态 DOM、网站脚本、验证记录，仅在本机保存，已排除版本控制。
- `test/core.test.cjs`：调度、停止、响应判定与旧脚本兼容性回归测试。

开发测试：

```text
node --test
node --check course-timer.user.js
```

真实源码包含个人页面信息和动态令牌，不应作为安装包分享；提供的 zip 只包含助手脚本、扩展入口和说明。实际提交成功分支目前仅通过代码与模拟返回值验证，不代表已成功选中课程。

后续精确配置所需信息：目标课程号、教学班或教师、开始日期和北京时间，以及是否接受备选教学班。
