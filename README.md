# 交大选课定时助手 · 页面刷新版 v0.4

在已登录的上海交通大学自主选课页面运行。将目标教学班加入任务，指定北京时间开始和结束时间。每轮对每门待抢课程执行：**在原网页搜索框输入课号 → 点击“查询” → 等待新的课程列表 → 加载并更新教学班余量 → 有名额才点击该班的“选课”**。

## 本次更新

- 即使课程已显示、上一轮已满，每轮也会重新输入课号并点击页面“查询”。例如课号为 EE2905，就用 EE2905 查询，而非反复读取旧列表。
- 必须收到本次查询对应的成功响应，并确认目标教学班所在列表重新渲染，才继续。网络错误、查询未完成或查不到目标时，本轮不提交。
- 教学班余量更新完成后再读取人数，取消原先固定等待 50 毫秒的做法。
- 刷新后保持目标教学班列表展开，便于直接查看更新后的余量。
- 面板显示每门课上次完成页面刷新的北京时间，以及当时读取的已选人数/容量。
- 保留多课程、跨类别任务；每轮依次处理全部未完成课程，再统一等待 5–60 秒。成功课程退出，全部成功或到设定结束时间时结束。

v0.3 使用独立接口查询，不会在满员时更新界面。v0.4 按新要求使用原页面的搜索框与查询按钮，取消这个后台查询分支。一个页面只有一个搜索框，多门课的查询、余量更新和提交因此按顺序进行，避免同时改写同一页面。某门查询失败后继续处理其他课程；等待该请求结束或超时会占用本轮时间。

例如设置 5 秒间隔、目标 A/B/C：查询 A 并处理 → 查询 B 并处理 → 查询 C 并处理 → 等待 5 秒 → 下一轮。课程之间不另加固定等待，但原网站类别切换限制、请求和弹窗会耗时。单门课则是每次完成查询处理后再等 5 秒。

这里的“刷新”是点击查询重建课程列表，不是 F5 重新载入整个网页。F5 会清除运行中的助手和任务。新名额以学校查询、余量接口和最终选课结果为准，刷新不能保证名额在提交时仍可用。

## 使用步骤

1. 在原网站选择课程类别、查询并展开课程，等待教学班人数和教师信息加载。
2. 点击助手“读取当前教学班”。在列表里选中目标班（Ctrl / Shift 可以多选），点击“添加所选教学班到任务”。
3. 可以更换网站查询或课程类别，重复添加。任务列表会保留之前的课程；同一门课不能添加多个教学班，修改时先移除旧班。
4. 核对任务列表中的教学班、教师和时间，填写**开始时间、结束时间（均为北京时间）**，设置每轮完成后的等待间隔（5–60 秒）。
5. 默认勾选“仅检查”：点击“执行检查”立即核对配置和当前能读取到的课程，不等待定时、不查询服务器、不提交。其他查询中的课程会提示正式运行时重新查询。
6. 正式执行时取消勾选“仅检查”，点击“启动定时选课”。开始时间已经过去但结束时间未到时立即开始。
7. 任务逐门显示“查询中”、检查次数、上次页面刷新时间和结果。到截止时间或全部成功时结束，也可点击“停止”。

运行期间避免手动修改原网站的选课类别、查询条件或同时选课。助手会自动切换到任务对应类别，用记录的课程号找回教学班；原网站的高级筛选条件可能影响查询，查不到课程时请清除不适用的条件。需要处理网站弹窗时可操作弹窗。

## 异常如何处理

| 状态 | 行为 |
| --- | --- |
| 余量为零 | 继续轮询，直到有名额或到截止时间 |
| 服务器确认成功 / 已选列表中有目标班 | 该课程完成，不再重复提交 |
| 网络问题、查询不到、学期变化等 | 显示原因并等待；纠正后下一轮重试 |
| 学校弹窗 | 等待你处理，可能暂时影响所有课程的页面操作 |
| 提交超时或返回无法判定 | 该课程标为“待人工核对”；不重复提交 |
| 人工核对确认未选上 | 点击该课程“已核对未选上，允许重试” |
| 不确定课程后来显示已选 | 在当前页面核实时标记成功 |

若选课提交时刚好被他人抢满，网站可能弹出“已无余量”提示，处理后可继续。若需要确认先修课、冲突、不可退课等提示，助手不会代你同意。

截止时间是助手停止开始新操作的时间：到时不再开始新的课程查询或点击选课，并停止等待未完成的页面查询。学校原页面已经发出的查询或选课请求、已经启动的网站校验/确认流程无法撤回，返回可能晚于截止时间，必须以网站已选列表为准。学校原函数包含同步请求；它阻塞页面时，停止按钮和计时器也可能延后执行。

## 为什么不必将 Edge 置顶

原版没有调用系统“始终置顶”，只是遇到 `document.visibilityState !== 'visible'` 就退出。这是原版为及时性添加的限制，v0.2 已移除。

后台运行仍有两种浏览器限制：

- 后台或最小化页面的 JavaScript 计时器可能降低执行频率，检查间隔会变长。见 [Chromium 官方计时器说明](https://developer.chrome.com/blog/timer-throttling-in-chrome-88)。
- Edge 休眠标签页会暂停网页。可在 Edge 性能设置中将 `i.sjtu.edu.cn` 加入不休眠站点名单。见 [Microsoft 休眠标签页说明](https://www.microsoft.com/edge/features/sleeping-tabs)。

所以现在可以切换其他窗口或标签页，**无需置顶**；若特别在意开抢时刻的及时性，保留前台更稳妥。电脑应保持唤醒、联网，选课网页保持打开。脚本不能保证后台不被限流，也不保证抢到名额。休眠后恢复时会先核对绝对结束时间，已过期则不再由助手开始选课。

刷新或关闭页面会取消任务，任务列表不跨刷新保存；本版不在网页关闭后运行，也不会自动登录或从尚未开放页面进入新一轮选课。

## 安装或更新

1. 解压 `dist/sjtu-course-timer.zip` 到固定目录。
2. Edge 地址栏打开 `edge://extensions`，启用“开发人员模式”，点击“加载解压缩的扩展”，选择包含 `manifest.json` 的目录。
3. 已安装旧版时，用新文件替换原扩展目录中的文件，在扩展管理页点击“重新加载”。
4. 刷新自主选课页面，确认面板标题为“交大选课定时助手 · 页面刷新 v0.4”。刷新前先结束已有任务；更新后需重新读取并添加课程，核对每门课的课号和教学班。

也可使用用户脚本管理器安装 `course-timer.user.js`（需要网页主环境，`@grant none`）。临时加载可复制整个 JS 文件到选课页 F12 控制台执行；如果已有旧面板，先刷新选课页。浏览器阻止粘贴时请采用本地扩展方式，不需要修改浏览器安全设置。

## 技术与验证

原生 JavaScript、DOM、Shadow DOM、网站自带 jQuery、Edge Manifest V3。无需 Python、后端、账户密码或导出 Cookie。扩展使用网页主环境，详见 [Chromium 官方文档](https://developer.chrome.com/docs/extensions/reference/manifest/content-scripts)。

- `course-timer.user.js`：完整运行脚本。
- `manifest.json`：扩展入口。
- `docs/source-analysis.md`：原网站源码分析及 v0.1 采集记录。
- `test/core.test.cjs`：每轮逐门查询、满员后重试、截止时间、取消、异常和原型兼容测试。
- `test/browser-fixture.html`：本地模拟网站，无学校网络请求；验证重复点击查询、新旧列表区分、渲染延迟、查询失败与取消、多课程选课完整流程、正常确认弹窗等待和界面任务列表。
- `artifacts/`：本机保存的原网站源码、动态 DOM 及验证记录，包含个人页面信息，不纳入安装包。

运行 `npm test` 和 `npm run check` 可执行 21 项调度测试及语法检查。在 Edge 打开 `test/browser-fixture.html` 可查看 17 项本地浏览器测试结果。v0.4 页面查询流程尚未在登录账户中实测，真实成功提交也未做账户实测；初版曾完成真实页面只读扫描和余量查询验证，模拟测试不代表已经选中课程。
