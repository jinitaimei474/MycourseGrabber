# 水源帖子导出工具

范围：一个指定主题中的主楼和回复。输入 URL、主题编号或标题；用户名可填多个精确账号或“全部”；起止时间采用北京时间，日期结束值包含全天。浏览器扩展及可直接加载的用户脚本复用当前登录态，只向水源发 GET 请求。

实现：core.js 负责输入校验、标题搜索、stream 分批抓取、去重、筛选、导出；panel.js 提供 Shadow DOM 表单、搜索选择、进度、停止和下载；manifest.json 限定水源域名。TXT 和 JSON 本地导出，正文保留 Markdown 原文及 HTML；TXT 显示原文或 HTML 转纯文本。完整性状态区分完成、中断、失败及缺失楼层。

请求每次至少间隔 1 秒，每批 20 楼，429 根据 Retry-After 等待，有限次数重试。保存开始时的 stream 快照，结束后新增的楼层不计入本次；不假设 ID 或楼层按时间单调排列。错误不冒充成功，用户停止后保留已匹配数据。导出不包含凭据，不自动上传。
