# 水源帖子导出

在已经登录的水源页面中输入**帖子网址 / 编号 / 标题**，指定**用户名或全部**和**北京时间范围**，导出该主题内的主楼和回复。每条内容附作者、楼层、发帖时间和原帖链接。

## 安装到 Edge

1. 解压 `dist/shuiyuan-crawler.zip` 到固定文件夹。
2. 在 Edge 地址栏输入 `edge://extensions`，打开“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择包含 `manifest.json` 的解压目录。
4. 打开或刷新已登录的 `https://shuiyuan.sjtu.edu.cn/`，右下角出现“水源 · 帖子导出”。

也可直接加载本项目的 `shuiyuan-crawler` 文件夹。已经使用 Tampermonkey 等脚本管理器时，可安装 `shuiyuan-crawler.user.js`。不需要 Python、服务器或 API Key。

临时使用：将 `shuiyuan-crawler.user.js` 全部复制到水源页面的开发者控制台执行。脚本本身只读取数据和添加面板；点击“开始爬取”才启动请求。刷新会移除临时面板。

## 输入示例

- 网址：`https://shuiyuan.sjtu.edu.cn/t/topic/12345/67`，其中主题编号是 `12345`，`67` 是楼层编号。
- 编号：`12345`。
- 标题：输入完整标题或关键词，点击“查找帖子”，在候选结果中选择目标；可以加载更多搜索结果。标题搜索依赖论坛自身的搜索索引，找不到时请用网址或编号。
- 用户：`全部`（也接受空白、`all`、`*`），或 `@alice, bob`。使用个人资料页 `/u/用户名` 中的账号，不是可重复的昵称；精确匹配，不区分大小写。
- 时间：`2026-09-01` 至 `2026-09-14` 包括北京时间 9 月 1 日 00:00:00 至 9 月 14 日 23:59:59.999。也支持 `2026-09-14 18:30:00`，精确时间的端点按该时刻包含；留空则不限制该端。

点击“开始爬取”，完成后下载 TXT 或 JSON。停止或网络异常后可以下载已经获取的部分结果；文件名和内容会标明“未完成”。刷新/关闭标签页会丢失尚未下载的结果，开始新任务会替换旧结果。

## 导出内容与范围

- TXT：标题、筛选条件、完整性状态，以及每条匹配内容的用户名、楼层、北京时间、链接和正文。正文优先使用接口提供的 Markdown 原文。
- JSON：除以上信息外，还保留服务器的 `created_at` UTC 时间、`updated_at`、`raw` 原文（如接口未返回则为 null）、`cooked` HTML、缺失与字段异常的楼层 ID。时间筛选使用**创建时间**，不是最后编辑时间。
- 抓取范围是**指定主题内**所有可返回的楼层（包括主楼和回复），不是全站按用户扫描；“全部”指该主题内的所有用户。
- 以开始时返回的 `post_stream.stream` 为楼层快照；运行期间新增楼层需要再次运行。遍历所有批次后本地筛选，避免依赖时间排序导致遗漏。
- 只导出当前账号能访问、接口实际返回的内容；已删除或不可见内容不会恢复。接口未返回已知楼层时明确报告缺失；未列入索引的不可见楼层不在可验证范围内。
- 导出正文及图片/附件链接，不下载图片和附件文件；不是历史版本备份。非常大的主题会花费较长时间并占用浏览器内存。
- 每批至多 20 楼，请求至少间隔 1 秒；每次请求 30 秒超时；HTTP 429/5xx 最多重试 3 次，遵守不超过 5 分钟的 Retry-After，超过则停止。支持立即停止后续请求。
- 无后台上传、不保存密码或 Cookie。扩展仅匹配水源域名，结果保留在页面内存并由你手动下载。

## 开发与验证

Node.js 24 已验证；扩展运行依赖近期版本的 Edge（支持 AbortSignal.any/timeout）。

```powershell
node --test shuiyuan-crawler/test/core.test.cjs
node --check shuiyuan-crawler/core.js
node --check shuiyuan-crawler/panel.js
./shuiyuan-crawler/build.ps1
```

`core.js` 负责请求和筛选，`panel.js` 负责交互；`build.ps1` 合并用户脚本并生成 ZIP。源码分析和现场验证记录见 `SOURCE-ANALYSIS.md`。
