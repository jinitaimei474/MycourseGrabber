# 交大助手 Windows 桌面版

用户要求：独立 Windows 软件，简约淡雅 UI；自动打开 Edge，经 jAccount 登录并进入自主选课；账号密码输入框仅补全网页空字段；复用多课程任务与刷新机制；预留水源帖子模块。

采用 Electron + playwright-core + Windows.Media.Ocr。Electron 仅加载本地界面，隔离上下文，网页只在专用 Edge 中打开。密码只在本进程内存保留，不落盘、不进入日志。Edge 使用独立持久化配置。查询、选课仍通过学校原界面及已验证的页面适配器，宿主程序持有调度和任务状态。

UI：暖白、浅青绿、细线边框；左侧模块导航，顶部浏览器状态；账号连接卡、查询与课程结果、最多十门任务、时间配置与运行日志。水源模块显示明确的待接入状态，模块注册与服务边界供后续扩展，不伪装已实现。

任务：同课多教学班按顺序备选；每次重新查询；全部成功或绝对截止时间终止；提交前持久化 uncertain，明确结果后更新；断线/刷新后不盲重试；停止立即取消等待。宿主每60分钟择机整页刷新，重新检查身份和学期。进程重启仅恢复配置，需人工开始。

登录：保留已有填充，仅补空字段；本地 OCR 限次尝试，密码错误/额外验证交给使用者；支持使用者直接在 Edge 完成后再连接。登录后悬浮选课菜单，点击自主选课，捕获新标签页。只有确认选课页加载且读取账户标识后才允许任务启动。

目录：desktop/src/main.cjs / preload.cjs / services/{browser,ocr,store,scheduler,model}.cjs / modules/index.cjs / ui/{index.html,app.js,style.css}；构建时复制根目录适配器到 desktop/vendor/，保留既有扩展。

验证：Node 调度/持久化测试；离线 Edge 验证登录字段补全、菜单跳转和页面桥接；Electron UI 烟测和截图；真实账户只读进入选课页，不提交真实选课。Windows x64 便携文件夹含 EXE 与运行依赖，交付启动快捷入口和开发说明。
