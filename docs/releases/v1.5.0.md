# SJTU Assistant v1.5.0 · 水源离线归档与跨帖检索

本版本将水源采集升级为可持续更新的本地资料库，并增加跨帖正文检索。既有课程助手和网球预约功能继续保留。

## 新增功能

- **项目归档**：采集前选择项目文件夹，自动识别已保存的主题，按帖子与楼层编号去重、追加新内容、更新编辑内容，并显示新增、更新、未变数量。缩小用户或时间范围、停止采集时，不删除此前保存的内容。
- **Markdown / HTML / JSON**：每条发言保留作者、发帖时间和原帖链接。HTML 保留引用、表格、代码块、折叠块等正文排版；JSON 保存原文、类别、标签和采集记录。资料库提供统一 HTML 目录。
- **离线图片**：水源自身托管的受支持图片保存到项目内并复用；优先显示已下载的原图，缩略图失败时仍可离线查看原图。资源未保存时记录原因并保留原链接。
- **跨帖正文检索**：在“搜索已保存内容”中搜索关键词，多个词用空格分隔、同时匹配；支持发言作者、北京时间范围、类别和标签组合筛选。作者支持多个用户名，类别和标签精确匹配。
- **定位楼层**：搜索结果显示正文摘要、作者及发帖时间，每页 30 条，按发帖时间倒序排列。点击结果在本地阅读窗口直接定位对应楼层。
- **旧项目兼容**：检索索引从已有 JSON 自动重建，无需重新采集、额外安装数据库或连接水源；更新采集内容后重新搜索即可。

## 修复与改进

- 保留正文段落边界，避免不同段落拼接产生误命中；支持中文短词及包含标点的字面关键词。
- 清理离线 HTML 的脚本、事件和危险链接；项目路径及楼层跳转校验限制在所选资料库中。
- JSON 保存采用临时文件替换并保留上一版本备份；损坏数据不会被静默重置。
- 修复网球服务测试中固定日期过期导致的误失败，仅调整测试日期，未更改预约逻辑。

## 下载与升级

下载 `SJTU-Assistant-v1.5.0-win32-x64.zip`，解压整个文件夹，再运行其中的 `SJTU-Assistant.exe`。支持 Windows 10/11 x64，需已安装 Microsoft Edge；最终用户无需安装 Node.js 或 Python。

请退出旧版后启动新版，不要只复制 EXE。课程配置和专用 Edge 登录配置仍使用原用户数据目录。选择原来的项目文件夹或 `shuiyuan-archive` 即可使用已归档资料；搬运资料时需保留整个 `shuiyuan-archive`，包括图片目录。发布附件提供 `SHA256SUMS.txt` 供校验。

## 使用提示与验证范围

- 资料库是历次采集的并集，不是当前网站的完整快照；已删除或无权访问的楼层不会被恢复，历史副本也不会因本次未返回而自动删除。
- 跨帖检索只覆盖当前项目已保存的正文。时间按北京时间和发帖时间筛选，仅填结束日期包含当天全天；修改条件或更新采集后需重新搜索。
- 自动生成的 `post.md` / `post.html` 会在更新或重新选择项目时重建，个人笔记请另存文件。
- 外部图片、音视频、SVG、附件及特殊论坛插件不保证离线还原。单图上限 10 MB，每主题每次最多尝试 100 个资源、保存 100 MB；失败详情见主题 JSON 的 `resource_warnings`。
- 水源登录已现场验证：首次需要完成 jAccount 认证；完成后，关闭助手和专用 Edge 再重新启动，本次测试可直接复用登录会话。会话失效后仍需重新认证。
- 84 项单元测试通过，并通过真实 Edge 模拟论坛测试、Electron 界面测试、断网图片显示及实际发布 EXE 的检索与楼层跳转测试。模拟内容测试与真实登录验证分别记录，不能据此保证所有真实帖子及论坛插件均已覆盖。

发布包不包含个人登录配置、Cookie、密码、测试资料库或实际采集内容。
