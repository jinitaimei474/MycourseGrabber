# SJTU Assistant v1.6.0 · jAccount 账号记忆

本版本加入可选的账号密码记忆：填写一次并点击“记住账号密码”，下次启动自动填充，课程、水源和网球共用同一组输入。继续保留 1.5.0 的水源离线归档、跨帖检索和楼层跳转功能。

## 新增功能

- **共用账号区**：三个模块使用页面顶部的 jAccount 账号密码，切换模块无需重复填写。
- **记住账号密码**：主动点击后才保存，重启自动填回。未点击记住时只在本次运行中使用；修改账号或密码后需再次点击记住。
- **Windows 加密保存**：账号和密码一起通过 Electron safeStorage / Windows DPAPI 加密，保存于本机用户数据目录的 `credentials.json`，不写入课程任务、网球配置或水源归档。
- **忘记账号密码**：删除助手保存的凭据与临时记录，清空输入和内存，重启后仍为空。此操作不退出 Edge 已登录的网站，也不删除任务或资料库。
- **水源认证页补全**：跳转到 jAccount 时补全空的账号密码字段，保留用户手动输入；验证码和登录确认仍需在 Edge 完成，再回助手点击连接。

## 修复与改进

- 状态刷新不会覆盖正在编辑的账号密码。
- 加密不可用时拒绝保存，保存失败保留原记录；文件损坏或无法解密时显示恢复提示。
- 修复长密码在错误消息截断后可能残留片段的问题，并屏蔽浏览器填写凭据失败时的原始异常，避免密码进入自动重新登录的调度状态或日志。
- 网球浏览器测试改用未来日期，消除固定日期过期导致的误失败；预约逻辑保持不变。

## 下载与升级

下载 `SJTU-Assistant-v1.6.0-win32-x64.zip` 和 `SHA256SUMS.txt`。支持 Windows 10/11 x64，需已安装 Microsoft Edge；最终用户无需安装 Node.js 或 Python。

退出旧版，解压完整目录，再运行 `SJTU-Assistant.exe`；不要只复制 EXE。课程与网球配置、专用 Edge 登录配置沿用原用户数据目录；水源归档继续选择原项目文件夹即可。GitHub 自动生成的 Source code 附件是源码，运行软件请下载上述 Windows ZIP。

首次使用：填写顶部账号密码 → 点击“记住账号密码” → 连接所需模块。凭据与当前 Windows 用户环境绑定，不作为跨电脑的密码备份；同一 Windows 用户权限下的其他程序仍可能解密。

## 验证与已知边界

- 使用虚构账号、隔离目录和真实 Windows 加密，验证了四次冷启动、不保存时退出即清空、记住后恢复、三个模块共用、忘记后重启为空，以及错误状态不泄漏密码。
- 打包后的 EXE 已验证账号记忆、归档、正文检索和楼层定位；本次未读取或验证用户真实密码。额外认证、失效会话和网站变化仍可能需要手动处理。
- 异常退出留下凭据临时文件时可能阻止再次保存；可点击“忘记账号密码”，再重新填写并记住。
