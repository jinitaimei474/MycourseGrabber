# Windows Desktop Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Deliver a Windows application managing Edge login, OCR, course discovery and durable scheduled enrollment.
**Architecture:** Local Electron UI and narrow IPC, Node scheduler and task store, Playwright Edge session, reusable in-page course adapter. Module registry reserves Shuiyuan integration.
**Tech Stack:** Electron 44.4.3, playwright-core 1.63.0, Windows.Media.Ocr, JavaScript, HTML/CSS.
**Spec:** docs/desktop-design.md

## Global Constraints
- At most ten courses, alternatives within course, absolute deadline, safe uncertain outcomes.
- Password remains memory-only; fill only empty website fields; no real enrollment during validation.
- Work in new desktop directory; preserve extension and shuiyuan-crawler. No commit/push requested.
- Run inline under the user's explicit implementation authorization; build a reviewable executable.

## Review Focus
- Submission interrupted by navigation or stop must stay uncertain after restart.
- Credential or account change cannot reuse another account's task queue.
- Deadline/stop must also cover browser navigation and login waits.
- UI cannot invoke concurrent query/connection during enrollment.
- Packaging must exclude profile data, private artifacts and saved credentials.
