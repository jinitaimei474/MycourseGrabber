# SJTU Assistant 水源模块接入

目标：在现有桌面软件内按主题标题、编号/网址、帖主检索，按类别/标签筛选，再按发言用户及可选北京时间范围采集和导出。帖主仅指主题发起人，不匹配仅参与回复的用户。

设计：复用现有 BrowserSession 专用 Edge 上下文，新建独立水源标签页，不改变课程标签页。首次需要在该 Edge 内登录水源，后续复用会话。模块持有检索结果、进度和采集结果；只允许同源 GET 接口，渲染器通过有限 IPC 调用。与课程操作共享互斥锁。结果仅留进程内存，TXT/JSON 通过系统保存对话框导出；不保存 Cookie 或密码到导出文件。

交互：左侧水源入口启用。连接区 → 搜索方式/关键词/类别/标签 → 可多选主题 → 发言用户名（默认全部）及时间 → 采集/停止/导出。仅选类别或标签也可检索。类别包含子类；单个标签精确筛选。显式加载更多，不宣称搜索覆盖全站。缺失、失败和中断均保留部分结果，显示完整性。预览最多 30 条，导出包含全部已采集内容。
