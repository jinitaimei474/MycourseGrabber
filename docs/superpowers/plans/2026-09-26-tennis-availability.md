# 网球实时余量与误禁用提示

用户要求扩展现有桌面模块：按某日、东区/胡晓明及时间下限列出所有空闲场次，持续刷新，单击或多选预约；关闭正常账号进入首页时错误显示的禁用提示。

实现范围：

- 通过原网页 `$ajax` 串行读取目标场馆运动类型、可预约日期、场地时段余量。严格匹配 `status` 为数字/字符串 0；时段按已核实的学校 07:00–22:00 映射。
- 主进程持有最新余量与候选身份，按日期、场馆、起止时间筛选；3–60 秒轮询，默认 5 秒。读取失败清空，过期列表不能预约。
- 页面显示场馆、小场地、时段、价格、更新时间。单项预约或多选（最多 30），多选按勾选顺序尝试；沿用同账号/同预约日锁，首个订单成功后停止。
- 监测与预约共用互斥锁，预约时先停止监测，再检查服务端余量与已有订单；保持二维码保存、倒计时及提醒。
- 核实 `/appointment/disabled/getAppintmentAndSysUserbyUser` 的账号状态，正常才关闭准确标题为“账号禁用提示”的对话框。观察晚到弹窗并重新核实状态；实际禁用或未知状态保留，不改服务端限制。
- 增加模型、服务、真实 Edge 模拟站点和 Electron 界面测试；覆盖余量减少、多选取消、监测不提交、交接只一单、重复保护，以及延迟弹窗/后续真实禁用。
- 发布 1.3.0，更新说明并检查实际 EXE。未使用真实账号下单或支付，线上仍需用户验证。
