# 水源跨帖检索与登录验证

需求：在所选资料库跨帖搜索正文，组合发言者、北京时间、类别和标签筛选，结果打开本地对应楼层；随后现场检查水源自动连接。

实现选择：使用运行时内置 SQLite FTS5 trigram 内存索引，避免额外原生依赖或修改现有 JSON 格式。选择项目时从 JSON 重建索引，采集更新时同步主题；JSON 保持唯一持久化来源。与直接扫描所有 JSON 相比省去每次搜索的重复读取，与落盘数据库相比无需额外迁移与文件锁。短于三个字符的关键词使用字面子串匹配，多个空格分隔词为 AND；作者可多选（OR），类别/标签精确筛选，时间沿用现有北京日期规则。结果按发帖时间倒序，每页 30 条，带命中摘要。

通过受限 IPC 仅接受筛选条件和主题/楼层数字 ID。主进程验证本地楼层存在、检查路径后用受限本地阅读窗口 loadFile(hash) 打开；不让 renderer 提交任意 file URL，不执行论坛脚本。切换项目清空结果，重新采集后标记需重新搜索。所有筛选候选来自本地资料，不依赖在线连接。

- [x] search.cjs 单元测试：中文长/短词、字面标点、组合筛选、边界日期、多作者、分页、更新去重、重新选择项目、无效跳转。
- [x] 接入 Archive、service、main/preload 与本地检索 UI，独立于线上搜索。
- [x] 验证 Electron 中 SQLite 可用，真实 UI 从搜索到本地楼层锚点，构建 1.5.0 并验证实际 EXE。
- [x] 使用软件专用 Edge 检查实际水源登录，记录可确认的会话状态；凭据或额外验证缺失时交由用户补充，不读取密码/Cookie 数据库。

登录验证只涉及用户授权的水源访问，不进行发帖、选课、预约或支付。当前改动叠加在用户现有 tennis3 工作区上，保留此前改动和 jaccount-captcha-extension。
